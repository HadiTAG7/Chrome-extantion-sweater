# مساعد حجوزات سويتر

إضافة لمتصفح Google Chrome تشتغل على صفحة الحجوزات في بوابة سويتر:
`https://ssp-portal.sweater.sa/bookings`

## وش تسوي؟

- **تخفي الغسلات اللي راح وقتها:** الغسلة تختفي بعد موعدها بـ 30 دقيقة، مهما كانت حالتها.
- **ترتّب الغسلات حسب الوقت:** الأقرب فوق.
- **تحدّث الصفحة كل 10 دقائق** تلقائياً.
- **تعرض كل غسلات اليوم بصفحة وحدة:** 50 صف بدل 10.
- **شريط صغير أسفل الصفحة** يوضح الوقت الباقي للتحديث، وعدد الغسلات السابقة المخفية، وفيه زر لإظهارها.

## التثبيت (مرة وحدة)

1. حمّل الملفات: من صفحة هذا الريبو في GitHub اضغط **Code** ثم **Download ZIP**.
2. فك الضغط عن الملف في مكان ثابت (مثلاً «المستندات»)، ولا تحذف المجلد بعدين لأن كروم يشغّل الإضافة منه.
3. افتح كروم واكتب في شريط العنوان: `chrome://extensions`
4. فعّل **وضع المطوّر (Developer mode)** من الزاوية العلوية.
5. اضغط **تحميل إضافة غير مضغوطة (Load unpacked)** واختر المجلد اللي فيه ملف `manifest.json`.
6. افتح صفحة الحجوزات، أو حدّثها لو كانت مفتوحة.

## الشريط

يطلع أسفل الصفحة في صفحة الحجوزات بس:

| يكتب | المعنى |
|---|---|
| «التحديث بعد 7:42» | الوقت الباقي على تحديث الصفحة |
| «التحديث مؤجل — نافذة مفتوحة» | فيه نافذة مفتوحة (مثل تفاصيل الحجز أو الفلاتر)، والتحديث ينتظر لين تقفلها |
| «التحديث مؤجل — استخدام حالي» | استخدمت الصفحة توّك، والتحديث ينتظر دقيقة عشان ما يقاطعك |
| «لا يوجد اتصال» | الإنترنت مقطوع؛ الإضافة تعيد المحاولة كل 30 ثانية بدل ما تحدّث على صفحة خطأ |
| «الغسلات السابقة: 3» وزر «إظهار» | عدد الغسلات المخفية؛ الزر يظهرها باهتة، ويرجع يخفيها |
| «⚠ فيه صفحات ثانية» | غسلات اليوم أكثر من 50، فالترتيب يشمل الصفحة الحالية بس |
| «⚠ توقيت الجهاز مو توقيت السعودية» | عدّل المنطقة الزمنية في إعدادات الجهاز عشان الإخفاء يصير على الوقت الصح |

## ملاحظات

- لو تركت الصفحة مفتوحة بعد منتصف الليل، تنتقل لحجوزات اليوم الجديد تلقائياً بعد الساعة 12:30، عشان آخر غسلات الأمس تكمل مهلتها.
- إذا اخترت تاريخ ثاني بنفسك، الإضافة ما تغيّره.
- ترتيب الأعمدة من الموقع (مثل Zone أو ID) ما يأثر، لأن الإضافة ترتّب دايماً حسب الوقت.
- احفظ رابط الصفحة في المفضلة **بدون تواريخ**: `https://ssp-portal.sweater.sa/bookings` والموقع يحط تاريخ اليوم بنفسه.
- الإضافة ما تطلب أي صلاحيات، وما ترسل أي بيانات لأي مكان؛ كل شغلها داخل المتصفح.

## تغيير الإعدادات

في أول ملف `content.js`:

```js
const REFRESH_MINUTES = 10; // كل كم دقيقة تتحدّث الصفحة
const GRACE_MINUTES = 30; // الغسلة تختفي بعد موعدها بكم دقيقة
const PAGE_SIZE = 50; // عدد الصفوف في الصفحة
```

بعد التعديل افتح `chrome://extensions` واضغط زر التحديث ↻ على الإضافة، ثم حدّث صفحة الحجوزات.
إذا طلع «⚠ فيه صفحات ثانية» تقدر تجرّب `PAGE_SIZE = 100`.

## تحديث الإضافة لنسخة جديدة

حمّل الملفات الجديدة واستبدل فيها القديمة في نفس المجلد، ثم اضغط ↻ على الإضافة في `chrome://extensions`.

## مشاكل شائعة

- **«Manifest file is missing or unreadable»:** اخترت مجلد غلط؛ اختر المجلد اللي فيه `manifest.json` مباشرة.
- **الشريط ما يطلع:** تأكد إن الإضافة مفعّلة في `chrome://extensions`، وحدّث صفحة الحجوزات.
- **أجهزة الشركة:** بعض الأجهزة تمنع الإضافات غير المضغوطة؛ كلّم قسم التقنية.
